# Portfólio Traço Arquitetura

Site estático (HTML/CSS/JS, sem build) hospedado no GitHub Pages.
Endereço: https://igorcarvalho-portifolio.github.io/portfolio-igor/

## Páginas
- `residencial.html`: lista de projetos residenciais
- `varejo.html` e `corporativo.html`: "em breve"
- `sobre.html`: Sobre nós (escritório e Igor)
- `projetos/<slug>/index.html`: uma página por projeto, com imagens em `images/`

## Projetos publicados
- `ape-35`: APÊ 35 (reforma, São Paulo, 2026, 35 m²)
- `apto-02`: APÊ 02 (reforma, São Paulo, 2025, 38 m²)
- `residencial-40`: RESIDENCIAL 40 (reforma, São Paulo, 2025, 40 m²)
- `terracota-marinho`: TERRACOTA & MARINHO (reforma, São Paulo, 2026, 40 m²)

## Regras
- Sem nomes de clientes no site; cada projeto tem um nome de referência
- Usar sempre a versão mais recente de cada render
- Cada novo projeto parte de uma página existente, com ficha, galeria, planta interativa, moodboard e lista de materiais

## Pendências
- Textos específicos para cada projeto (hoje são parecidos entre si)
- Revisão dos textos pelo Igor, logo original e foto melhor do Igor
- Projetos de Varejo e Corporativo
- Endereço definitivo / domínio próprio
